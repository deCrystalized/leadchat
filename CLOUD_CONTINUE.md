# LeadChat: облачное продолжение нового дизайна

Актуальная рабочая копия и инструкция находятся в [cloud-work/HANDOFF.md](cloud-work/HANDOFF.md). Это отдельная ветка для продолжения разработки; main и существующие исходники сохранены.

Начать с чтения HANDOFF.md, затем `python3 cloud-work/prepare.py`. Кандидат извлекается в `design-workspace/frontend`, нативные исходники в `design-workspace/native`, неизменяемый актуальный референс в `design-workspace/reference`. Использовать их вместо более старых исходников из main. Полная приёмка открыта: 96 известных падений и оставшиеся проверки перечислены в инструкции. Не обращаться к production и не отправлять сообщения клиентам. Один исполнитель, без субагентов.

Пакет проверен локальной распаковкой и хешами; загрузка в GitHub сама по себе не запускает облачную задачу. Для работы при выключенном Mac нужна опубликованная приватная Codex Cloud environment и запущенная задача на этой ветке.
